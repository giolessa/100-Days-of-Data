# 100 Days of Data: Roadmap

A 100-day study challenge focused on **data analysis and data engineering**, with the goal of landing an internship.

- **Day 1:** 2026-11-14 (Saturday)
- **Day 100:** 2027-02-21 (Sunday)
- **Intensive sprint:** days 5 to 32 (2026-11-18 to 2026-12-15)
- **Consolidation:** days 33 to 100 (2026-12-16 to 2027-02-21)

## Tools and topics

SQL · Python · Pandas · NumPy · Power BI · data fundamentals · cloud computing (AWS certification) · pipelines · portfolio projects

## Weekly routine (sprint)

| Day | Time | Theme |
|---|---|---|
| Monday | 20:20–23:20 | SQL |
| Tuesday | 20:20–23:20 | Pandas |
| Wednesday | 20:20–23:20 | NumPy / Python (or Pandas in weeks 1 and 3) |
| Thursday | 20:20–23:20 | Power BI (or SQL in week 1) |
| Friday | 08:30–11:30 | Cloud (certification prep) |
| Saturday | all day | Project and heavy practice |
| Sunday | part of the day | Review, documentation, cloud mock exam |

**Night structure (3h):** 1h new content, 1h exercises, 30 min review and notes.

## Cloud certification

Target: **AWS Certified Cloud Practitioner (CLF-C02)**.

- Format: 90 minutes, 65 scored questions, passing score 700/1000, fee about US$100 (check the price at checkout, it can vary with the exchange rate).
- Target window: week of 2026-12-14 to 2026-12-20, only if mock exam scores are consistently around 80% or higher. Otherwise postpone by one or two weeks.

## Rules

1. **Minimum day:** on busy days, 1 hour of review or one exercise keeps the streak alive.
2. **University exam or deadline week:** becomes a light week (review plus one exercise per day), and the delayed module moves to the next Saturday.
3. **Every module ends with documentation** in English, pushed to the repository.
4. **Every 2 weeks:** a short review of what was done and what slipped, to adjust the plan.
