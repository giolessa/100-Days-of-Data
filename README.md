# 100 Days of Data 

A 100-day challenge documenting my daily journey into Data Engineering and Analytics. Centralizing code, SQL queries, Python scripts, and ETL projects in a single repository.

## Repository Structure

- `01-sql/` - Queries, window functions, and database challenges.
- `02-python/` - Data manipulation, Pandas, and automation scripts.
- `03-data-modeling/` - Dimensional modeling, Star Schema, and notes.
- `04-etl-pipelines/` - Data ingestion and processing workflows.
- `05-bi-and-visualization/` - Dashboards and metrics.
- `06-projects/` - Comprehensive end-to-end data projects.
